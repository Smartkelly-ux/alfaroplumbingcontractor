# Alfaro Plumbing Contractor LLC

## Local development

Prerequisite: Node.js.

```sh
npm install
npm run dev
```

## Build and deploy

Create the production site with:

```sh
npm run build
```

Upload the contents of the generated `dist` directory to any static web host. The build uses relative asset paths, so it can also be served from a subdirectory.

To test the production build locally, run `npm run preview`.
